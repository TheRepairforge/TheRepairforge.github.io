Repair tools for batteries that aren't dead yet.

Open tools from The Repair Forge, a YouTube channel about repairing and restoring cordless power tools.

See how it works

A battery that won't charge is not always dead.

Sometimes the battery's management board has stored a lock while the cells are fine. The charger can't tell the difference, so the battery gets thrown away.

These tools read what the board remembers, tell you whether the pack can be saved, and clear the lock only when it is a false one.
