A Makita battery tester you build yourself.

Reads Makita LXT 18 V batteries, gives one verdict, and clears false lockouts. An ESP32, a screen and a knob. No PC.

ESP32-C3 on the carrier PCB

The reference build. A rotary knob and a back button, a two-layer board with a handful of hand-solderable parts. Fabricated and bench-validated.

Build guide and the printed case on Printables

CYD (ESP32-2432S028R)

The "Cheap Yellow Display": same firmware, a touch screen, less soldering. Boards vary between batches, so check yours against the notes first.

CYD guide

Flash the firmware

Plug the board in with a data USB cable, pick your board, click Install.

This browser can't flash a board: use Chrome or Edge on a computer. Flashing needs a secure (https) page.

Japanese firmware (日本語): ESP32-C3ESP32-C3 or CYDCYD. The other builds carry English, French, German and Spanish.

Works in Chrome and Edge on a computer. Anywhere else, download the firmware from the latest release and flash it with esptool, or build it from source.

If it doesn't go as planned

  • Board not detected. On the ESP32-C3, hold BOOT while plugging it in. On Windows the CYD may need the CH340 USB driver.
  • Mirrored image on the CYD (text reads right to left, the title bar looks olive green). Some CYDs have an ILI9341 screen: install the cyd-ili9341 file from the releasethe cyd-ili9341 file from the release instead, then run Settings > Calibrate touch once. Details in the CYD guide.
  • Erase device wipes the saved language and the touch calibration. Leave it unticked for an update.
  • Which version is on it? The About screen shows it.
