Build a PocketOBI

The reference build: an ESP32-C3 SuperMini on the PocketOBI carrier board, a 2.4" screen with a rotary encoder, and a Makita LXT adapter.

You need: the carrier PCB (Gerbers are ready to upload), the parts on the BOM, an LXT adapter, a soldering iron and a USB-C cable.

The one trap: identify DATA and ENABLE by the ESP32 silkscreen, not by the adapter's connector numbering. B+ is never connected.

  • Order the PCB PocketOBI / hardware / README.md
  • Parts list hardware / PocketOBI-HW-BOM.csv
  • Wire the Makita LXT adapter
  • Pinout and hardware notes PocketOBI / HARDWARE.md
  • Print the case Printables

Build it on a CYD instead

The "Cheap Yellow Display" runs the same firmware with a touch screen instead of the knob. Less soldering, but boards vary between batches. The ESP32-C3 build stays the reference.

You need: an ESP32-2432S028R (dual-USB, ST7789 revision), two 470 Ω resistors, an LXT adapter.

  • The step-by-step CYD guide PocketOBI / docs / CYD_GUIDE.md
  • Which CYD to buy PocketOBI / CYD_NOTES.md

Put the firmware on it

The fastest way is from this site: plug the board in, pick it, click Install. No toolchain to set up.

You need: Chrome or Edge on a computer, and a USB cable that carries data (not a charge-only one).

  • Flash it from your browser
  • Build from source with PlatformIO or the Arduino IDE PocketOBI / README.md

Read batteries on your PC

Put PocketOBI in PC bridge mode, plug it in by USB, and PackScope reads through it. Every reading is saved, per pack.

You need: a PocketOBI and a Windows, macOS or Linux computer. To try PackScope first, its demo mode needs no hardware.

  • Download PackScope
  • Run it from source PackScope / README.md
