How it works

Look at the screens

Each language page shows every device screen and the main app screens as they are today.

Fix one string, or all of them

Next to each string, Suggest a fix opens a GitHub issue already filled in: you only type your version. For a full pass, download the spreadsheet, fill the suggestion column and attach it to an issue.

We check it on the real screen

Every accepted fix is rendered on the device screen before it ships, so a long word never ends up cut off. You are credited in the release notes if you want to be.

You need a free GitHub account to open an issue. Each tool has its own issue tracker, so a device string and an app string go to different places; the buttons pick the right one.
